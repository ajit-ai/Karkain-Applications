22-websocket — A19 WebSocket (blocked)
========================================

No implementation. Karkain 1.1.0 provides no WebSocket capability
(no handshake, frame codec, or event/push primitives), confirmed by
source scan. This directory holds documentation only. There is no
partial WebSocket support anywhere in this laboratory.
